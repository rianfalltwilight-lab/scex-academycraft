# 能力屏蔽方块

能力屏蔽方块可以识别每个人的AIM力场，并对被识别的AIM力场发射高频率音波，以此影响能力者使用能力。

能力屏蔽方块拥有开关，白名单和屏蔽距离的控制，最大可以达到一百格。能力屏蔽方块只能被其放置者更改其信息。

当然了，能力屏蔽方块这么高端，你们世界中的材料不足以合成，只有创造模式才能获得。

# 指令

能力管理指令要求管理员权限（权限等级 2）。输入 __/aim__ 或 __/aim help__ 可查看完整帮助。

__/aim__ 作用于执行指令的玩家；__/aimp <玩家或选择器>__ 可由管理员或服务器控制台管理指定在线玩家。它们可以设置能力系与 Level、学习或取消技能、调整熟练度、恢复 CP、清除冷却、切换开发者模式及重置能力数据。

能力系与技能参数既可填写稳定 ID，也可直接使用 __catlist__ 与 __skills__ 输出的可复制 __#索引__。

常用示例：

- __/aim cat electromaster__：将自己设为电击使，Level 1。
- __/aim level 5__：将自己的能力等级设为 Level 5。
- __/aimp Steve level 5__：将在线玩家 Steve 设为 Level 5。
- __/aim learn_all__：学习当前能力系的所有技能。
- __/aim exp arc_gen 1__：将电弧激发熟练度设为 100%。
- __/aim fullcp__：回满 CP 并清空过载。

这些是调试/管理功能，会绕过正常成长流程并影响游戏平衡。
