========================================================================================================================

This readme explains how to add custom media to AcademyCraft. The content root is .minecraft/acmedia/.

1. Put a music file into .minecraft/acmedia/source (.ogg is the only supported format).
2. Put a square .png cover with the same base name into .minecraft/acmedia/cover.
3. Start the game and open the Media Player app. External tracks are available automatically, and their names and descriptions can be edited in the app.

Safety limits: at most 256 external tracks, 512 MiB per Ogg file, and 2048x2048 / 16 MiB per cover.

========================================================================================================================

本 README 介绍如何向 AcademyCraft 添加自定义媒体，内容根目录为 .minecraft/acmedia/。

1. 将音乐文件放入 .minecraft/acmedia/source（目前仅支持 .ogg）。
2. 将同名的方形 .png 封面放入 .minecraft/acmedia/cover。
3. 启动游戏并打开媒体播放器 App。外部曲目会自动可用，曲名和说明可直接在 App 内编辑。

安全限制：最多读取 256 首外部曲目；每个 Ogg 最大 512 MiB；每张封面最大 2048x2048、16 MiB。
