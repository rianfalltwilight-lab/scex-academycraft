# 0.0.23-scex-wireless

[直接下载运行 JAR](https://github.com/rianfalltwilight-lab/scex-academycraft/releases/download/v0.0.23-scex-wireless/AcademyCraft-neoforge-1.21.1-0.0.23-scex-wireless.jar)

修复矩阵界面先编辑 SSID、再输入密码并回车时，只提交密码却显示通用保存成功的问题。现在一起提交实际编辑的字段，并等待匹配当前界面和操作的服务器回执；拒绝或超时保留待保存提示，Escape 撤销草稿，未编辑字段不会覆盖服务器更新。

冻结交付验证：343 项 JUnit、286 项 GameTest 通过。真实 GUI 旧版复现 Unnamed，新版 4 项断言与 3 张截图审阅通过，覆盖组合保存、节点列表、新中文名称、重开菜单。579 PNG / 440 JSON 检查通过，资源与 0.0.22 相同。独立解压构建得到同一运行 JAR；并非完全禁用构建缓存。

**协议升级为 payload-v16-data-v4，客户端与服务端必须同步升级，不能与 0.0.22 混用。** 存档结构不变；未做完整包、多人竞争和退出后世界重载验收。0.0.21 的 2.5 倍是发电产出倍率，不是伤害倍率。

本次为开发预发布。运行 JAR 使用本地冻结程序与资源，补齐公开身份/许可证/构建记录；发布清单列出原始与公开产物 SHA-256、条目差异。未部署生产。
